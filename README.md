# Web Development Classwork 💻

Welcome to my **Web Development Classwork** repository! This repository contains my daily classroom coding practice, practical exercises, and programs based on my web development syllabus.

My goal is to strengthen my frontend and backend development skills through consistent practice and hands-on learning.

## 📚 Syllabus & Topics Covered

### Unit 1: Introduction to React Fundamentals
- Introduction to React and setting up a React application using VS Code
- Rendering elements and JSX expressions
- Rendering multiple elements and lists
- Conditional rendering
- Functional components and props
- Bootstrap in React
- Dynamic classes and expressions
- Event handling and component composition
- Component styling and form handling

### Unit 2: React Router and Hooks
**React Router**
- BrowserRouter, Routes, Route, Link, and NavLink
- Nested routes and index routes
- Dynamic routes and query strings
- Lazy routing
- Passing props to routed components

**React Hooks**
- Introduction to React Hooks
- useState and useEffect
- useContext and useReducer
- useCallback and useMemo
- useRef
- Using useContext and useReducer to manage shared state

### Unit 3: RESTful API Calling with React
- Introduction to frontend applications and RESTful web services
- JSON fundamentals
- Fetch API
- Introduction to Axios
- Making GET, POST, PUT, and DELETE requests
- API integration in React applications
- Form handling in React

### Unit 4: Introduction to Node.js
- Setting up Node.js and npm
- Creating a basic Node.js server
- Handling HTTP requests and responses
- Introduction to Express.js
- Configuring routes and working with Express
- Asynchronous JavaScript
- Callbacks and Promises

### Unit 5: Building RESTful APIs with Node.js and Express.js
- Introduction to RESTful APIs and REST principles
- HTTP methods and status codes
- Building API endpoints with Express.js
- Express middleware and error handling
- Designing and implementing API routes
- Integrating MongoDB with Mongoose

## 🛠️ Technologies & Tools

- **Frontend:** React.js, HTML, CSS, Bootstrap, JavaScript
- **Routing:** React Router
- **API Integration:** Fetch API, Axios, REST APIs
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **Code Editor:** Visual Studio Code
- **Version Control:** Git and GitHub
